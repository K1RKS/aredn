aredn-traceroute — help 0.1.25-r0

Expanded version of aredn-traceroute -h: what it is, how to run it, how to read a hop line, and common examples.

Usage

aredn-traceroute [options] <destination>

destination is a mesh node name, hostname, or IPv4 address. If you pass a bare node name (no dots), .local.mesh is added for the probe. Illegal characters are rejected.

What this tool is

A side-loaded AREDN package that runs the normal BusyBox traceroute, then adds mesh-aware columns so you can see how you reached each hop — not just that you did.

On the node it also replaces Tools → Traceroute’s CGI (/www/cgi-bin/traceroute), so the web UI shows the same enriched hops when this package is installed on the source node. Removing the package restores the stock firmware CGI.

Under the hood: one /a/sysinfo?lqm=1 fetch per hop node (cached), link type and tx/rx quality from the previous hop’s LQM neighbor entry, and Babel path metric from this node’s installed host routes.

Typical output

Stock traceroute banner first, then the package banner (so Tools UI still shows version/metric — it skips CGI lines until traceroute to…), then hop lines:

traceroute to nocall-far-node.local.mesh (10.9.8.7), 30 hops max, 46 byte packets
Aredn-Traceroute(0.1.25-r0): Babel Metric 4078
 1 nocall-x86-node (10.1.2.3) 23 ms DtD 96/96 (100%/100%) 352 0%
 2 nocall-mid-node (10.1.2.4) 45 ms RF 3593/3520 (98%/99%) 3945 1%
 3 nocall-far-node (10.9.8.7) 61 ms WG 133/133 (100%/100%) 4078 0%

Hostnames omit .local.mesh. RTT is whole milliseconds. Fields are single-spaced. Missing values are -.

Example hop and field meanings

 1 nocall-x86-node (10.1.2.3) 23 ms DtD 96/96 (100%/100%) 352 0%
hop#

Traceroute hop number (TTL). Same as stock traceroute.

name (ip)

Resolved hop hostname and the address traceroute actually saw. If traceroute only returned an IP, the name may be filled from that hop’s sysinfo or from the previous hop’s LQM neighbor list.

RTT

Round-trip time for the probe that got a reply at this hop, rounded to an integer number of milliseconds.

type

Incoming link type on the edge into this hop, from the previous hop’s LQM: DtD (device-to-device), RF (radio), WG (WireGuard tunnel), or Xlink.

tx/rx

Babel/LQM link costs from the previous hop’s neighbor entry: txcost/rxcost. Shown when -tx_rx_info is on (default).

(tx%/rx%)

TX and RX success percentages from LQM (rev_lq and lq — same idea as the neighbor-device UI). Shown with -tx_rx_info.

met

Babel path metric from the traceroute source node to this hop (installed host route). May show “-” for some tunnel/WG hop IPs that are not in local host routes; the final hop often matches the banner Babel Metric.

err

Neighbor errors percent from LQM: 100 − rev_quality. Shown with -tx_rx_info.

With -gps, lat,lon is inserted after RTT. With --node_version, the hop’s AREDN firmware_version is appended at the end.

Options

  -tx_rx_info       Include txcost/rxcost, (tx%/rx%), neighborErrors% (default)
  -no_tx_rx_info    Omit those tx/rx fields (wins over -tx_rx_info)
  --node_version    Append each hop's AREDN firmware_version (off by default)
  -gps              Include per-hop GPS coordinates (off by default)
  -verbose          Explain why displayed fields are unset (-)
  -h, --help        Show short help on the node

If both -tx_rx_info and -no_tx_rx_info are given, -no_tx_rx_info always wins.

How to use it

CLI on a node

# Basic (tx/rx columns on)
aredn-traceroute nocall-x86-node

# Narrower line — type + Babel metric only
aredn-traceroute -no_tx_rx_info nocall-far-node

# Show firmware on each hop
aredn-traceroute --node_version nocall-far-node

# GPS + verbose notes for missing fields
aredn-traceroute -gps -verbose nocall-far-node

Tools → Traceroute (web UI)

Install the APK on the source node (the one in the Source field). The UI still draws its own “Traceroute test started / Source / Target” chrome, then streams the CGI. You should see the Aredn-Traceroute(…) banner right after traceroute to…, then enriched hops.

CGI query extras (if you call the CGI directly): gps=1, verbose=1, node_version=1, tx_rx_info=0 or no_tx_rx_info=1.

Install / remove

# On the node (Status → Packages, allow untrusted), or:
apk add --allow-untrusted aredn-traceroute-0.1.25-r0.apk

# Remove restores stock Tools traceroute CGI
apk del aredn-traceroute
