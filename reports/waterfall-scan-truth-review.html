Short answer: No. Only “current channel + current BW” with a successful FFT path is closely truthful. Wider plot than scan, ALL (time-multiplexed), and survey fallback all show something easy to misread as a full FFT across the axis.

Contract: plot BW vs scan BW

GUI BW is the waterfall axis width (plotBw), not necessarily the RF listen width. scanBw = widest bandwidth the radio advertises that is ≤ plotBw. Retune/listen uses scanBw.

ALL forces both channel and BW to ALL. Plot spans the band; each section listens at max scanBw (often 80 on hAP).

Where the plot lies (or tells a partial truth)

1. Plot wider than scan

plot 40 / scan 20 → stretch. Looks full-axis; measured ~20 MHz.

2. ALL is a hop movie

Sequential sections. Empty regions mean “not tuned there.”

3. Survey is not an FFT waterfall

Occupancy, not sub-bin spectrum.

4. Off-channel only if retune verifies

Failed verify → skip/error rather than paint the wrong channel on the axis.

What does match when FFT works

Verified dwell on channel C at scanBw S with plotBw = S: TLV samples near C mapped across C±S/2 are a real spectral snapshot of that listen window. Color is relative (UI-normalized), not calibrated dBm.

ath10k widths 11/22/44/88 → 10/20/40/80. Out-of-band bins skipped. Far-off-channel FFT dropped.

How to read the UI

  1. Trust title: plot vs scan MHz and section count.
  2. If note says survey/fallback — occupancy, not spectrum.
  3. ALL: Y = which section was live, not whole band at once.
  4. Prefer plot BW ≤ what the radio can open (often = current BW) for truthful FFT.
