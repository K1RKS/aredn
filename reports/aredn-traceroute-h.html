aredn-traceroute -h 0.1.25-r0

Exact CLI help text from the package binary.

Usage: aredn-traceroute [options] <destination>
  Runs traceroute and appends per-hop link type and Babel path metric.
  Link type (and optional tx/rx fields) come from the previous hop's LQM.
  Each node is queried at most once via /a/sysinfo?lqm=1.
  Banner (after traceroute to …) shows package version and Babel path metric.

  Example hop (defaults; -tx_rx_info on):
    1 nocall-x86-node (10.1.2.3) 23 ms DtD 96/96 (100%/100%) 352 0%

  Fields:
    hop#       Traceroute hop number (TTL).
    name (ip)  Hop hostname and address.
    RTT        Round-trip time in whole milliseconds.
    type       Incoming link type: DtD, RF, WG, or Xlink.
    tx/rx      LQM txcost/rxcost from the previous hop (with -tx_rx_info).
    (tx%/rx%)  TX/RX success from LQM rev_lq/lq (with -tx_rx_info).
    met        Babel path metric from this node to the hop.
    err        Neighbor errors% = 100-rev_quality (with -tx_rx_info).
    With -gps: lat,lon after RTT.  With --node_version: firmware at end.

  -tx_rx_info       Include txcost/rxcost, (tx%/rx%), neighborErrors% (default)
  -no_tx_rx_info    Omit those tx/rx fields (wins over -tx_rx_info)
  --node_version    Append each hop's AREDN firmware_version (off by default)
  -gps              Include per-hop GPS coordinates (off by default)
  -verbose          Explain why displayed fields are unset (-)
