stableroute APK module

Side-loaded CLI that runs traceroute N times, groups full ordered hop paths, and reports stability with per-hop RTT avg ± max deviation.

stableroute CLI only stock /bin/traceroute v0.1.0-r0

Path equality Ordered hop sequences are compared in full. nodea→nodeb→nodec and noded→nodee→nodec are different paths even when both have depth 3. RTT does not affect path identity.

Aggregation flow

StepAction
1Parse destination and -n N
2For each run: /bin/traceroute -q 1 -w 1 dest
3Parse hop lines → ordered hop list
4Path key = hop1|hop2|… (identity only)
5Bucket count + collect per-hop RTTs
6Print summary, then unique paths by frequency

Per unique path

Occurrence count and % of N. Each hop shows identity plus avg Xms +- Yms where Y is max |rtt − avg| over samples for that hop on that path. No RTT samples → -.
